## 💻 Featured Projects

### 🔐 AI-Assisted SOC Alert Triage Platform
**Python • Threat Intelligence • Security Automation**
Collects and analyzes security alerts, extracts suspicious indicators, enriches them with threat intelligence, and helps generate incident reports so SOC analysts can investigate faster.

### 🛡️ AI-Powered Phishing Detection System
**Python • Scikit-learn • Flask • React.js • PostgreSQL**
A full-stack application that uses machine learning to detect suspicious URLs and phishing emails. Each result gets a 0–100 risk score and a list of explainable indicators showing why the content looks suspicious.

### 🤖 Coding Agent
**Python • Anthropic API • AI Agents**
A small sandboxed coding agent that inspects a project, modifies files, runs tests, and iterates toward a solution. Its safety controls include path restrictions, secret-file blocking, command allowlists, confirmation requirements, and execution limits.

### 🔎 API Security Tester
**Python • FastAPI • Requests • PostgreSQL • Docker**
Analyzes APIs for common security issues in authentication, authorization, input validation, error handling, security headers, and CORS. It requires explicit permission before testing an API and stores findings for analysis.

### ⚙️ Triad: Release Readiness System
**Python • Node.js • Multi-Agent Architecture**
A multi-agent system that evaluates whether a full-stack repository is ready for release, built for CI-friendly workflows.
* **Tracker** runs tests, linters, dependency checks, and repository analysis
* **Predictor** evaluates risk and identifies the main risk drivers
* **Commander** makes a `GO` or `HOLD` decision and can apply safe automated fixes
